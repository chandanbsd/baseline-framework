# Features
covers: the features of the baseline skills, one page each

## Features

- [Set up a repository](set-up-a-repository.md): initialise a repository for the baseline after a dry run.
- [Update a repository](update-a-repository.md): bring a repository to the installed version, migration by migration.
- [The pull request check](pull-request-check.md): the `baseline check` that guards the shape of `baseline/` on every pull request.
- [Questions before code](questions-before-code.md): agree the end state in a file the engineer accepts before any code.
- [Documentation from the code](documentation-from-the-code.md): a fresh agent documents the accepted code and raises flags.
- [Decisions and standards](decisions-and-standards.md): ADRs and standards that steer agent-written code.

`baseline-refactor` is installed with the other three skills but is a placeholder: invoked, it tells the engineer it is not implemented and stops.
